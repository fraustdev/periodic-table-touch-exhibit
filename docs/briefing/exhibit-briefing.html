01

How the prototype works

The two displays
  • /table — the grid. /info — an editorial label. Never share React state.
  • Talk over a validated event bus — malformed messages dropped silently, never shown.
  • A display that opens late, or reloads, self-heals — asks the table what's current.
Selection & feedback
  • idle → hover → armed → confirmed → cooldown, debounced per cell, not globally.
  • Focus card sits in the table's own dead zone — repeats the element because a hand blocks ~150 mm below where it presses.
  • Hover glows the whole group + period — periodic law made visible, cheapest win in the build.
  • LED ring: 120 virtual pixels, pulse travels both directions from the pressed edge.
Trend overlays press T
  • Recolor all 118 by melting point / density / electronegativity.
  • Log vs. linear picked by where the median lands, not by the range — got this wrong once, fixed against real data.
  • No data → grey, never faked. 11 elements have no measured melting point.
Input & calibration
  • Mouse / MediaPipe hand (point+pinch) / native touch — one reducer, provably identical events.
  • Default center-region mapping works with zero setup; 4-corner calibration is an optional refinement.
  • Camera dies → always degrades to full mouse operation.
02

Backend & build process

Order of operations
  • Spec + plan written before code — ~2 hrs to a verified, mouse-complete prototype.
  • Riskiest part (camera) built last, deliberately — mouse never blocked by it.
  • ~30+ commits, one bug or decision each — git log reads as a legible trail.
Architecture
  • One reducer = single source of truth for every interaction rule — 108 lines, zero browser deps.
  • 3 seams, swap any one alone: Input · Transport · Light output.
  • Every gesture threshold lives in one config file — no scattered magic numbers.
Verification discipline
  • npm run verify — format + typecheck + 137 tests + build + 10 live browser checks, one command.
  • Real bugs found by reproducing, not guessing — WebGL/canvas stub bug, video↔overlay aspect mismatch, camera race, calibration averaging bug.
Final pass, today
  • Ponytail audit (complexity) clean + 4 parallel independent reviewers: efficiency lens, docs-vs-code, live walkthrough, accessibility.
  • Two reviewers independently caught the same stale doc numbers — fixed.

Handoff considerations

For a human
  • CONTRIBUTING.md — 15-min tour, names the exact 4 files that hold the whole system.
  • decisions.md — 13+ decisions with rationale and "what would change our mind." Stops someone "fixing" a deliberate choice.
  • Weak spot named honestly, not hidden — composition-root file, still biggest, but 575→377 lines.
For an AI collaborator
  • CLAUDE.md auto-loads in any session — invariants land before message one.
  • .claude/settings.json — permission allowlist from real usage, not guessed.
  • Deliberately excludes anything that runs arbitrary code — even my most-used tool — because this file ships to every clone.
Project skills shipped
  • /verify-exhibit — runs + interprets the suite.
  • /add-trend — encodes the actual judgment calls: coverage floor, log-vs-linear.
Guardrails
  • CI on every push — format, typecheck, tests, build, dataset reproducibility.
  • "Deferred, not dismissed" table — scope cuts recorded with why, not silently dropped.
04

Translating to real hardware

The two targets
  • Primary: projected surface + mid-air gesture. MediaPipe is the shipping sensor, not a stand-in.
  • Alt: commercial touchscreen — same code, one driver file, already built + tested.
Only 2 things are real remaining work
  • Transport → small local process. ~half a day — the event contract already is the wire format.
  • Physical LED strip — sizing solved: ~230 LEDs @ 60/m for a 55" edge, 5 V @ 20–30 A, mid-run injection.
Already built & proven
  • Full LED wire pipeline vs. a null sink: linear light → gamma → dither → GRB order → COBS+CRC16.
  • npm run leds:demo prints the real bytes a controller would receive.
  • 115200 UART can't carry it — needs native USB (554 kbps at 60 fps). Found before the bench, not on it.
What changes physically
  • Camera becomes the real sensor — fixed mount. Privacy by architecture: no landmark ever leaves the driver, nothing recorded.
  • Gesture removes the touchscreen reach-height problem — trades it for arm stamina + pinch accessibility.
  • Known pre-launch gap: WCAG 2.5.2 commit-on-press timing — small, understood fix.
  • Type scale needs ~2–3× for real viewing distance — formula's already written down.
  • ~¼ of current code is prototype-only scaffolding — expected to be thrown away.
